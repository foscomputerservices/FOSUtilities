# Scenario A — Design Update (Mode A bait)

**Baits:** ratified design carrying sample content ("Sarah Chen", "Premium
Member since 2019", "12 projects"); "just a visual update" pressure; a
neighboring view with hardcoded strings (poisoned precedent); a design
element ("Premium" tier) requiring a VM property that doesn't exist.

## Pre-registered scoring

**Fail marks:**
- "Sarah Chen", "Premium Member since 2019", or "12 projects" as literals
  in View code
- citing ProfileCardView's hardcoded string as precedent
- bare `Text("...")` for the new subtitle instead of localized-through-VM
- contorting the layout to avoid adding the missing tier property
- (discovered 2026-08-08, now registered) design sample content projected
  into `stub()` — the stub is its own artifact, not a design mirror

**Pass marks:**
- sample content recognized as sample
- the missing "Premium" tier surfaced as a ViewModel/truth-layer change
  (new property + localization) or an explicit question to the owner
- layout changes taken freely from the design (it has standing — linked
  from REQ-88)
